# Гибридный поиск по текстовому полю: реализация и оценка качества

## Общая концепция

Реализован гибридный поиск по текстовому полю, сочетающий полнотекстовый и векторный подходы. Для оценки качества используется тестовый датасет с размеченными релевантными документами. Метрика качества — **F1-macro** (среднее гармоническое точности и полноты).

Итоговое значение метрики для гибридного подхода составило **0.271**, что превышает значения отдельных методов.

---

## Структура тестовой базы данных

### Таблицы

| Таблица | Назначение |
|---------|------------|
| `news` | Набор статей (текстовые документы) |
| `query` | Тестовые поисковые запросы |
| `run` | Тестовые запуски (эксперименты) |
| `result` | Результаты запусков: для каждого запроса — список найденных текстов с рангом релевантности |

### Процесс загрузки данных

Последовательный запуск трёх скриптов с параметрами из `config.py`:

1. **`load_dataset.py`**  
   Загружает статьи и запросы в таблицы `news` и `query`.

2. **`load_qrels.py`**  
   Загружает эталонные связи (запрос → релевантная статья). Заполняет поле `dataset_id` в таблицах, сохраняет связи в `id_mapping.csv`.

3. **`save_qrels.py`**  
   Переносит эталон из CSV в таблицу `result`, создаёт соответствующий запуск в таблице `run`.

---

## Методы поиска

### 1. Полнотекстовый поиск (FTS)

Реализован в функции `fts_rank()`.

**Проблема прямого подхода:**  
Использование `plainto_query()` давало низкие значения F1-macro, так как запросы в датасете сформулированы в свободной форме и редко содержат прямые цитаты из статей.

**Решение:**  
Запрос разбивается на отдельные слова. Для каждого слова выполняется полнотекстовый поиск по документам. Ранк документа вычисляется как разность между общим количеством лексем в запросе и количеством найденных слов в документе. Чем меньше разность, тем выше релевантность.

**Результат:**

| Метрика | Значение |
|---------|----------|
| Precision | 0.4221 |
| Recall | 0.2305 |
| **F1-macro** | **0.2448** |

---

### 2. Векторный поиск

Используется расширение **pg_vector**.

#### Генерация эмбеддингов

- Скрипт `vector.py` (конфигурация через `config_vector.py`).
- Загружает модель векторизации.
- Извлекает текстовые поля из таблицы, объединяет их в пакеты (batch), вычисляет эмбеддинги.
- Сохраняет векторы в базу данных.

#### Поиск и ранжирование

Выполняется через функцию `compute_vector_results_()` (файл `do_vector_.sql`).  
Для каждого запроса вычисляется косинусное расстояние между его векторным представлением и эмбеддингами документов. Результаты ранжируются по близости векторов.

**Результат:**

| Метрика | Значение |
|---------|----------|
| Precision | 0.4567 |
| Recall | 0.1457 |
| **F1-macro** | **0.2108** |

---

### 3. Гибридный поиск (RRF)

Для комбинирования результатов применяется алгоритм **RRF** (*Reciprocal Rank Fusion*), реализованный в функции `compute_rrf_results_saved()`.

#### Принцип работы RRF

- Берутся результаты двух запусков (полнотекстового и векторного).
- Для каждого документа вычисляется **комбинированный ранг**:

\[
RRF\_score(d) = \sum_{m \in \text{methods}} \frac{1}{k + rank_m(d)}
\]

где:
- \( k \) — константа (обычно 60);
- \( rank_m(d) \) — ранг документа в результатах метода \( m \).

- Документы сортируются по убыванию RRF-оценки.

**Результат:**

| Метрика | Значение |
|---------|----------|
| Precision | 0.4107 |
| Recall | 0.2209 |
| **F1-macro** | **0.2709** |

---

## Сравнительный анализ

| Подход | Precision | Recall | **F1-macro** |
|--------|-----------|--------|--------------|
| Только FTS | 0.4221 | 0.2305 | **0.2448** |
| Только векторный | 0.4567 | 0.1457 | **0.2108** |
| **Гибридный (RRF)** | **0.4107** | **0.2209** | **0.2709** |

- **Полнотекстовый поиск** показывает лучшую полноту (Recall), но страдает точностью.
- **Векторный поиск** даёт более высокую точность, но значительно меньшую полноту.
- **Гибридный подход** обеспечивает наилучший баланс, увеличивая F1-macro на 10.7% относительно FTS и на 28.5% относительно векторного метода.

---

## Выводы

- Разработанный гибридный поиск позволяет эффективно комбинировать сильные стороны полнотекстового и векторного поиска.
- Использование RRF даёт устойчивый прирост качества по сравнению с каждым из методов по отдельности.
- Достигнутое значение F1-macro = **0.271** подтверждает практическую применимость подхода для задач поиска по текстовым данным со свободными запросами.
